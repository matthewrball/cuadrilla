What changes

Each agent gets a mouse

A session can open several mice. Another agent opens its own session. The cursors stay separate.

Apps are leased

The second mouse that enters a leased app gets lease_conflict. It does not click through the first mouse’s work.

A false ok does not count

Typing has to show up in the next window read. Cuadrilla does not treat a driver ok as success.

Install

Install cua-driver first. Then:

git clone --depth 1 https://github.com/matthewrball/cuadrilla.git
./cuadrilla/install.sh

That puts cuadrilla on your PATH, writes the skill where Claude, Codex, Hermes, and omp look, and adds an MCP server named cuadrilla. Restart an agent that is already open so it reconnects.

cuadrilla demo --keep
cuadrilla press 1
cuadrilla type hello
cuadrilla stop

Limits, stated

Cua Driver is still the engine

Cuadrilla does not reimplement window input. Clicks and typing go through Cua Driver. The fork is github.com/matthewrball/cua.

Hardware input still takes turns

cua-driver 0.44 admits one hardware action at a time. Cuadrilla overlaps scheduling and keeps same-app actions in order. cuadrilla doctor reports parallel_hid: false until that changes.

Questions

What is Cuadrilla?

Cuadrilla is an open-source crew for computer-use agents on macOS. Each session owns up to eight mice. Each mouse has its own cursor. Agents lease apps, so they do not drive the same window or take the desktop pointer.

Does Cuadrilla replace Cua Driver?

No. Cua Driver is the engine that clicks and types into windows. Cuadrilla is the crew: leases, several mice, verification, and a cmux status pill.

Will it take over my mouse?

No. Desktop input is refused. There is no focus-stealing mode. when_idle waits until you stop typing, then gives up.

Can several agents work at once?

Yes, in separate apps. Hardware input inside the current driver still takes turns. The desktop pointer stays yours.

What does it cost?

Nothing. The license is MIT.
