Install Cuadrilla

macOS is the tested host. You need cua-driver first, with Accessibility and Screen Recording granted to Cua Driver.

  1. Clone the repo and run the installer. 
    git clone --depth 1 https://github.com/matthewrball/cuadrilla.git
./cuadrilla/install.sh

    That links ~/.local/bin/cuadrilla, writes the skill for Claude, Codex, Hermes, and omp, and adds an MCP server named cuadrilla.

  2. Restart an agent that is already open.

    The skill is on disk immediately. MCP reconnects when the agent starts again.

  3. Try a crew without taking the pointer. 
    cuadrilla demo --keep
cuadrilla press 1
cuadrilla type hello
cuadrilla stop
